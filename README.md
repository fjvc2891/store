Full Stack – Java + React 
Blossom
🎯 Objective
Develop a full-stack e-commerce application that allows managing products, 
users, and orders. 
The backend must be in Java with Spring Boot, using PostgreSQL as the 
database, and the frontend must be implemented in React. 
The candidate will be assessed on their ability to: 
• Model data and complex relationships. 
• Build secure and robust APIs. 
• Create a functional and usable web interface. 
• Implement best practices for testing and documentation. 
• Self-manage time and project organization.
⚙ Technical Requirements 
Backend (Java + Spring Boot)
1. Data modeling (Hibernate/JPA)
• Entities: User, Product, Order. 
• Relationships: 
◦ A User can have multiple Orders. 
◦ An Order can contain multiple Products. 
• Include at least one example of inheritance in the entities. 
2. Product management
• Full CRUD endpoints. 
• Product search by name, category, and price range. 
3. User management
• User registration. 
• Login with credential validation.
⚙ Technical Requirements 
Backend (Java + Spring Boot)
4. Order management
• Create an order with one or more products. 
• Retrieve a user’s order history. 
5. Security
• Authentication and authorization with JWT. 
6. Testing (minimum 80% coverage)
• Unit and integration tests. 
• Use MockMvc to test endpoints.
Frontend (React) 
1.Minimum required screens: 
◦ Login and User Registration. 
◦ Product list with filters (name, category, price). 
◦ Product detail. 
◦ Shopping cart (add/remove products). 
◦ Order history for the authenticated user. 
2.Frontend requirements: 
◦ State management with Redux or Context API. 
◦ Styling is open (use of Material UI or Tailwind is valued). 
◦ Calls to the backend using fetch/axios. 
◦ Form validations. 
◦ Proper error and loading state handling.
Extras (Optional but valued) 
• Use Docker to package the application. 
• Use Swagger/OpenAPI to document the API. 
• Frontend unit tests (React Testing Library / Jest). 
• Responsive design on the frontend.
📄 Theoretical Questions 
Answer in a separate document: 
1. Explain how you would implement the Repository pattern in this project. 
2. Differences between JPA and Hibernate and in which cases you would use 
each. 
3. What advantages does React offer compared to other frontend frameworks? 
4. Explain how you would organize your time over 2 days to deliver this 
assignment.
📦 Deliverables 
1. Git repository with the source code (backend and frontend). 
2. README with: 
◦ Instructions to run the backend and frontend locally. 
◦ Endpoint documentation (Swagger or manual). 
◦ Notes on design decisions and challenges encountered. 
3.Automated tests included in the backend (and optional in the frontend). 
4. Short demo video or screenshots showing the complete flow of: 
◦ Registration/login. 
◦ Product listing and search. 
◦ Order creation. 
◦ Order history retrieval.
